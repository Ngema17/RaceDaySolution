##  Project Overview
This repository contains the backend RESTful API for the RaceDay system, built for Part 2 of the POE. The API serves as the backbone for the MVC front-end (Part 3), handling data operations, strict role-based access, and automated testing. 

The API is built using **ASP.NET Core Web API**, utilizes **Entity Framework Core (Code-First)** for database management, and implements **Session-based authentication** with password hashing.
